# Curriculum map

[Home](../README.md)

The current material includes the four-lesson [Understanding AI in Everyday Life orientation](../orientation/README.md), followed by three substantive interaction modules. Start with either sequence according to learners' experience. Later dedicated domains are a roadmap, not completed teaching material.

| Long-term domain | v0.1 coverage |
| --- | --- |
| Recognizing AI and explaining how a response is produced | Orientation lessons 01–02 |
| Data, design, incentives, and privacy choices | Orientation lesson 03 |
| AI, access, accountability, labor, and material resources | Orientation lesson 04 |
| What Interaction Literacy Is | Foundations and module 01 |
| From Prompting to Interaction | Module 01 |
| Context, Framing, and Model Behavior | Module 01, introductory |
| Capability ≠ Authority | Module 02 |
| Verification and Epistemic Discipline | Module 03 |
| Human Judgment and Delegation | Module 02, introductory |
| Memory, Continuity, and Context | Brief example in module 02; dedicated module planned |
| Consent and Relational Boundaries | Brief example in module 02; dedicated module planned |
| Collaboration Without Cognitive Surrender | Across exercises; dedicated module planned |
| Productive Disagreement and Epistemic Friction | Debriefs; dedicated module planned |
| Authorship, Attribution, and AI-Assisted Creation | Dedicated module planned |
| Reflection, Metacognition, and Learning With AI | Exit reflections; dedicated module planned |

Next development should prioritize memory/consent and authorship, then test whether learners transfer these ideas to unfamiliar cases. Do not infer validation from curricular coverage.

For a route connecting these lessons with embodied digital life, dialogue, and case reasoning, use the [Commons learning route](https://github.com/TrivianInstitute/educator-commons/blob/main/pathways/ai-literacy-and-embodied-digital-life.md). Its transfer activity is formative, not evidence that transfer has already occurred.
