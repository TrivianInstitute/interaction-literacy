# Working glossary

[Home](../README.md) · Definitions for this curriculum, open to revision

| Term | Working meaning | Caution |
| --- | --- | --- |
| Agency | Capacity and opportunity to participate in choices and action | Not equivalent to doing everything alone |
| Capability | What a system can technically do in a setting | Does not establish permission |
| Authority | Legitimate scope to decide or act in a context | May be disputed or limited by other obligations |
| Delegation | Assigning a bounded task or discretion to another actor or system | Does not erase accountability |
| Consent | Contextual agreement to a specified participation or action | A prior preference may not settle present agreement |
| Context | Information and conditions shaping an exchange | Availability is not correct interpretation |
| Continuity | Persistence of relevant context across interactions | Not necessarily memory of everything or continuing consent |
| Verification | Checking a claim against appropriate evidence | Repetition is not independent corroboration |
| Epistemic friction | Productive resistance that invites examination of a claim | Disagreement alone does not establish truth |
| Cognitive surrender | Here, giving up examination of consequential judgments to an output | An interpretive term, not a diagnosis |
| Relational significance | Meaning an interaction has for a participant | Does not settle machine subjectivity |
| Non-domination | A normative commitment against unchecked power over others | Requires attention to institutions as well as individual choice |
