# Plain-language glossary

[Pathway](README.md) · Working definitions for these lessons

The definitions below explain how terms are used in this pathway. They simplify a larger technical field and can be revised. See the linked [technical sources](sources.md) and the existing [Interaction Literacy glossary](../glossary/README.md) for more context.

| Term | Meaning here | Question that makes it useful |
| --- | --- | --- |
| AI system or service | An arrangement that uses AI capabilities within an application and a setting. The model is one component. | What else shapes what happens here? |
| Machine learning | Developing a model's behavior through training with data. | What examples and objectives shaped it? |
| Model | A computational component that maps inputs to outputs using its structure and parameters. | What task is this model being asked to perform? |
| Parameters | Numerical values adjusted during model training. | Is a change happening here, or elsewhere in the application? |
| Training | A process that changes model parameters using data and a learning objective. | What was changed and evaluated? |
| Inference | Applying a model to an input to obtain an output. | What information is available for this response? |
| Token | A unit in a model's representation of language, often a word, word-part, or punctuation. | Is a claim about tokens being confused with a claim about truth? |
| Current context | Information supplied for a particular response. | Is the relevant instruction or source actually present? |
| Retrieval | Finding information from an accessible collection or source. | Which source was found, and is it suitable? |
| Saved application memory | Stored information that a service may supply in later interactions. | What persists, who can access it, and how can it change? |
| Generation | Producing content such as text, images, or audio. | What did the system create, and what needs checking? |
| Classification | Assigning a category, often using a model's prediction. | What does an incorrect label do in this setting? |
| Ranking | Ordering possibilities according to chosen criteria or scores. | Why does this item come first? |
| Objective | What a training or application process is set up to favor. | Does this measure serve the person's purpose? |
| Incentive | A reason an organization or participant may favor an outcome. | What supports this interpretation of its priorities? |
| Representation | Whose situations and which conditions appear in a dataset or design process. | Who or what is missing, and why might that matter? |
| Confabulation | Generated content that presents incorrect information as if it were reliable. | What evidence supports the claim itself? |
| Delegated action | A task carried out through permissions and connections supplied to an application. | Who authorized it, and does that authorization still apply? |
| Provenance | Information about where material came from and how it was produced or changed. | Can this claim be connected to a relevant source or record? |
| Transfer | Applying an idea in a different situation. | Can I generate useful questions in an unfamiliar case? |

“Unknown” is a useful conclusion when the service's behavior or documentation does not establish an answer. The next move is to name evidence that could resolve the uncertainty.
