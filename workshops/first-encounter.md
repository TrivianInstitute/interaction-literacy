# A 90-minute first encounter

[Home](../README.md) · Libraries, community programs, and staff learning

**Outcome:** participants can separate purpose, evidence, and authority in one AI-supported decision. This workshop introduces selected activities; it does not complete all three modules.

**Materials:** the [interaction map](../exercises/interaction-map.md), [claim packet](../exercises/claim-ledger.md), paper or accessible text, and a timer. No account needed.

| Minutes | Activity |
| --- | --- |
| 0–10 | Introduce purpose and participation options; distinguish framing, evidence, authority |
| 10–30 | Map the fictional library workshop; compare assumptions |
| 30–40 | Revise the request and identify who decides |
| 40–45 | Break, with optional movement or quiet rest |
| 45–65 | Read the fictional evidence packet and build a ledger |
| 65–80 | Compare recommendations; name what could change them |
| 80–90 | Exit response and voluntary feedback |

**Exit response:** “My recommendation is __, supported by __, limited by __. Before anyone executes it, __ must authorize __.”

Use the [facilitator guide](../facilitator-guides/running-a-session.md). If time is short, reduce reporting, not private reasoning or the break. Invite continued study through module 02 rather than suggesting this introduction qualifies someone to govern consequential systems.
